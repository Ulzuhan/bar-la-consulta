Qué es una base de datos

Una base de datos guarda la información en tablas, como las hojas de un Excel. Cada fila es una cosa (un plato, una comanda) y cada columna es un dato suyo (el precio, la fecha).

Las tablas se relacionan por sus ids. Cada comanda tiene un camarero_id: es el id de una fila de la tabla personal. Así el nombre del camarero se guarda una sola vez y no en cada comanda.

SQL es el idioma para pedirle datos a una base de datos. Se dice qué se quiere, no cómo conseguirlo. La base de datos de la clase es SQLite, la misma que se usa desde Python con sqlite3 y pandas.

La forma de una consulta

Las piezas van siempre en este orden. En las consultas de esta clase siempre hay SELECT y FROM; las demás se ponen cuando hacen falta:

SELECT columnas          -- qué quiero ver
FROM tabla               -- de dónde
WHERE condiciones        -- qué filas
GROUP BY columnas        -- cómo agrupo
HAVING condiciones       -- qué grupos
ORDER BY columnas        -- cómo ordeno
LIMIT número;            -- cuántas filas
  • Las palabras de SQL se escriben en mayúsculas por costumbre, para distinguirlas de los nombres de las tablas y las columnas. En minúsculas también funcionan.
  • Los textos y las fechas van entre comillas simples: 'terraza', '2026-10-31'.
  • Las fechas se escriben año-mes-día, y así se pueden comparar y ordenar como textos.
  • -- empieza un comentario: lo que va detrás no se ejecuta.
  • El ; marca el final de la consulta.

SELECT: elegir columnas

* son todas las columnas. Si no, se escriben separadas por comas, en el orden en que se quieren ver.

SELECT * FROM carta;
SELECT plato, precio FROM carta;

En pandas: carta[["plato", "precio"]]

LIMIT: unas pocas filas

Va siempre al final. Sin ORDER BY da filas cualesquiera.

SELECT * FROM comandas LIMIT 5;

En pandas: comandas.head(5)

DISTINCT: sin repetir

Cada valor una sola vez.

SELECT DISTINCT categoria FROM carta;

En pandas: carta["categoria"].unique()

Cálculos y AS

Se puede operar con las columnas (+ - * /). AS le pone nombre a la columna del resultado. La tabla no cambia.

SELECT plato, precio, precio * 1.10 AS precio_nuevo FROM carta;

WHERE: filtrar filas

Se queda con las filas que cumplen la condición. Se compara con =, !=, >, <, >= y <=. Para igual se escribe un solo =: SQLite también acepta ==, como Python, pero otros motores no, así que es mejor acostumbrarse a =. En SQLite el = distingue mayúsculas: 'Postres' no es 'postres'.

SELECT plato, precio
FROM carta
WHERE precio > 10;
SELECT plato, categoria
FROM carta
WHERE categoria = 'postres';
SELECT *
FROM comandas
WHERE fecha = '2026-10-31';

En pandas: carta[carta["precio"] > 10]

AND y OR

Con AND se tienen que cumplir las dos condiciones; con OR, basta una. AND se hace antes que OR: si se mezclan, paréntesis.

SELECT plato, precio
FROM carta
WHERE categoria = 'tapas' AND precio < 4;
SELECT plato, categoria
FROM carta
WHERE categoria = 'postres' OR categoria = 'bebidas';
SELECT plato, categoria, precio
FROM carta
WHERE (categoria = 'tapas' OR categoria = 'raciones') AND precio > 10;

En pandas: (carta["categoria"] == "tapas") & (carta["precio"] < 4)

IN y BETWEEN

IN es una lista de valores (como varios OR). BETWEEN es un rango e incluye los dos extremos; también vale con fechas.

SELECT plato, categoria
FROM carta
WHERE categoria IN ('postres', 'bebidas');
SELECT plato, precio
FROM carta
WHERE precio BETWEEN 5 AND 8;

En pandas: carta["categoria"].isin(["postres", "bebidas"]) y carta["precio"].between(5, 8)

LIKE: buscar texto

% es “cualquier cosa”. 'Bocadillo%' empieza por Bocadillo; '%queso%' contiene queso. En SQLite, LIKE no distingue mayúsculas en las letras sin tilde: '%queso%' encuentra “Queso manchego”. Con tildes sí las distingue: 'ó%' no encuentra a “Óscar”, y '%JAMÓN%' no encuentra “Croquetas de jamón”.

SELECT plato
FROM carta
WHERE plato LIKE 'Bocadillo%';
SELECT plato
FROM carta
WHERE plato LIKE '%queso%';

En pandas: carta["plato"].str.contains("queso", case=False)

ORDER BY: ordenar

De menor a mayor si no se dice nada; DESC es de mayor a menor. Con LIMIT, el top: los 5 más caros.

SELECT plato, precio
FROM carta
ORDER BY precio DESC;
SELECT plato, precio
FROM carta
ORDER BY precio DESC
LIMIT 5;

En pandas: carta.sort_values("precio", ascending=False).head(5)

COUNT, SUM, AVG, MIN y MAX

Convierten muchas filas en un número: cuántas hay, la suma, la media, el mínimo y el máximo. ROUND(número, 2) deja dos decimales.

SELECT COUNT(*) FROM comandas;
SELECT COUNT(*) AS num_comandas
FROM comandas
WHERE pago = 'efectivo';
SELECT ROUND(AVG(total), 2) AS ticket_medio FROM comandas;
SELECT MIN(precio) AS mas_barato, MAX(precio) AS mas_caro FROM carta;

En pandas: len(comandas), comandas["total"].sum(), comandas["total"].mean()

GROUP BY: por grupos

Hace el cálculo una vez por cada grupo. Lo que va en el SELECT tiene que estar en el GROUP BY o dentro de COUNT, SUM, AVG…

SELECT categoria, COUNT(*) AS num_platos
FROM carta
GROUP BY categoria;
SELECT pago, COUNT(*) AS num_comandas
FROM comandas
GROUP BY pago
ORDER BY num_comandas DESC;

En pandas: carta.groupby("categoria").size() y comandas["pago"].value_counts()

HAVING: filtrar grupos

WHERE filtra filas antes de agrupar; HAVING filtra los grupos después. En el WHERE no se puede usar COUNT ni SUM.

SELECT categoria, COUNT(*) AS num_platos
FROM carta
GROUP BY categoria
HAVING COUNT(*) > 5;

NULL: la casilla vacía

NULL es que no hay dato: no es 0 ni un texto vacío. Se busca con IS NULL o IS NOT NULL, nunca con = NULL.

SELECT plato, alergenos
FROM carta
WHERE alergenos IS NULL;

En pandas: carta[carta["alergenos"].isna()]

CASE: crear categorías

El if de SQL. Se queda con el primer WHEN que se cumple; si no se cumple ninguno, el ELSE.

SELECT plato, precio,
  CASE
    WHEN precio >= 10 THEN 'cara'
    ELSE 'normal'
  END AS gama
FROM carta;

JOIN: juntar dos tablas

Junta cada fila de una tabla con la fila de la otra cuyo id coincide. Delante de cada columna se escribe su tabla.

SELECT comandas.id, comandas.total, personal.nombre
FROM comandas
JOIN personal ON comandas.camarero_id = personal.id;
SELECT personal.nombre, COUNT(*) AS num_comandas
FROM comandas
JOIN personal ON comandas.camarero_id = personal.id
GROUP BY personal.nombre
ORDER BY num_comandas DESC;

En pandas: comandas.merge(personal, left_on="camarero_id", right_on="id")

Errores típicos

Lo que ves Qué pasa
no such column: terraza Falta poner el texto entre comillas: 'terraza'
no such column con un nombre de columna Está mal escrito. Mira el panel de tablas
No sale ninguna fila Mayúsculas o tildes en el texto que buscas ('Terraza', 'salón')
near "FROM": syntax error Una coma de más antes del FROM, o las piezas en otro orden
misuse of aggregate COUNT o SUM en el WHERE: va en el HAVING
incomplete input Falta cerrar una comilla o un paréntesis
Salen muchos decimales Es normal en los ordenadores: ROUND(número, 2)
TOP da error TOP es de SQL Server. En SQLite es LIMIT al final
