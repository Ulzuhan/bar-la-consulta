# Bar La Consulta · Laboratorio de SQL

Una página para aprender SQL desde cero en el navegador, sin instalar nada: SQLite funciona dentro de la propia página (con [sql.js](https://sql.js.org)) y los ejercicios se corrigen solos.

- **Laboratorio:** https://ulzuhan.github.io/bar-la-consulta/
- **Teoría:** https://ulzuhan.github.io/bar-la-consulta/teoria.html
- **La base de datos:** `bar.db` (SQLite), con la carta, el personal y las comandas de un bar inventado, y las tablas de un pequeño caso para resolver.

Lo que cada persona escribe se guarda solo en su navegador.
